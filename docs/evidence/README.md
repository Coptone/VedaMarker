# Curated evidence

Only redacted, reviewable evidence summaries belong here. Do not commit raw
capture ZIPs, JSONL files, character names, account/Content IDs, world names,
chat, or unreviewed diagnostic logs.

Each accepted mapping should state:

- client region and game version;
- territory and encounter phase;
- source capture/session alias;
- observed event sequence;
- interpretation and confidence;
- reviewer and verification date.
